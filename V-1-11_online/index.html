Энэ хуудас юу вэ?

          
F.CSM302 Үйлдлийн систем, бие даалт V-1-11 — Dining-Philosophers асуудлын Pthreads шийдэл. Энэ хуудсаар төслийг юу ч суулгахгүйгээр (gcc, make, Linux хэрэггүй) шууд туршина.

          

            
1. UI симуляторMonitor ба Naive горимыг төлөвийн диаграм, дугуй ширээгээр алхам алхмаар харуулна. Энэ нь src/dining_philosophers.html файл өөрөө.

            
2. C програмsrc/philosophers.c-ийн яг ижил код-ыг WebAssembly болгож хөрвүүлсэн. Аргумент, log, SUMMARY мөр, гарах код (0/1/2/3) Linux дээрхтэй ижил.

            
3. Автомат тестmake test-ийн 63 тест (T, E, D, L) ижил аргумент, ижил шалгуураар браузерт ажиллана.

          

        

        

          
C код браузерт яаж ажилладаг вэ?

          
    
            
  1. clang --target=wasm32-wasi нь src/philosophers.c-г өөрчлөхгүйгээр WebAssembly болгоно (web/build.sh).
    2. 
            
  2. Браузерт Linux-ийн thread байхгүй тул <pthread.h>-ийн оронд web/pthread.h орно. Pthread-ийн функц бүрийг web/runtime.js гүйцэтгэнэ.
    3. 
            
  3. Thread бүр өөрийн стектэй. Mutex, condition variable, sleep, join дээр хүлээх үед runtime тэр thread-ийн стекийг хадгалаад өөр thread-ийг ажиллуулна (Binaryen Asyncify). Mutex дараалсан хүлээгчид FIFO-оор шилжинэ.
    4. 
          

          
Ялгаа: браузерт бүх thread нэг CPU цөм дээр ээлжилж ажиллана. Thread зөвхөн хүлээх үедээ бусдад ээлж өгнө. Тиймээс monitor-ийн логик, log-ийн дараалал, deadlock илрүүлэлт, гарах кодыг бүрэн шалгана. Харин жинхэнэ зэрэгцээ ажиллагаа болон ThreadSanitizer-ийг Linux дээр шалгана (доор). Мөн санамсаргүй тоог browser-ийн C сан (musl) өөрөөр гаргадаг тул нэг seed-тэй ч хугацаанууд Linux-ийн log-оос өөр гарч болно. Дүрэм, үр дүн ижил.

        

        

          
Жинхэнэ Linux дээр турших (суулгалтгүй)

          
GitHub Codespaces — браузерт Linux терминал нээгдэнэ. gcc, make бэлэн байна. GitHub бүртгэл хэрэгтэй.

          
Codespaces-д нээх

          
Нээгдсэний дараа доод терминалд:

          
make test        # 63 тест (жинхэнэ pthread)
make run         # 5 хүн, monitor
make deadlock    # naive горимд deadlock (rc=3)
make tsan        # ThreadSanitizer: data race шалгах

          
Өөрийн Linux/macOS дээр: git clone → make → make test (дэлгэрэнгүй: README, Manual B1–B4).
